# 📊 E-Commerce Data Analysis

## 📌 Project Overview

This project focuses on analyzing an e-commerce dataset to extract meaningful business insights. The project includes **data cleaning, exploratory data analysis (EDA), SQL analysis, and an interactive Power BI dashboard**.

The goal is to understand customer behavior, sales performance, product trends, and other important business metrics that can support data-driven decision-making.

---

## 🎯 Objectives

* Clean and preprocess raw e-commerce data.
* Perform Exploratory Data Analysis (EDA).
* Analyze the dataset using SQL queries.
* Identify important sales and customer trends.
* Create an interactive Power BI dashboard.
* Generate meaningful business insights from the data.
